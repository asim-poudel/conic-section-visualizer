CONIC SECTION 3D VISUALIZER - CONTROL GUIDE
============================================

This application visualizes conic sections formed by the intersection
of a plane with a double-napped cone.

CONTROLS
--------
- Mouse Drag in 3D Viewport: Rotate camera
- Mouse Scroll: Zoom in/out
- Sliders at bottom: Adjust horizontal/vertical rotation

INPUT PARAMETERS
----------------

CONE PARAMETERS:
  k (slope): Controls the steepness of the cone (default: 1.0)
             Larger k = wider cone, smaller k = narrower cone
  Height:    Height of each nappe of the cone (default: 5.0)

PLANE EQUATION (Ax + By + Cz + D = 0):
  A, B, C:   Normal vector components of the plane
  D:         Distance parameter (offset from origin)


VALUES FOR DIFFERENT CONIC SECTIONS
-----------------------------------

1. CIRCLE (Plane perpendicular to cone axis)
   A = 0     B = 0     C = 1     D = -2
   A = 0     B = 0     C = 1     D = -3

2. ELLIPSE (Plane steeper than cone edge)
   A = 0     B = 1     C = 2     D = -3
   A = 1     B = 0     C = 3     D = -4
   A = 1     B = 1     C = 4     D = -5

3. PARABOLA (Plane parallel to cone edge)
   A = 0     B = 1     C = 1     D = -2
   A = 1     B = 0     C = 1     D = -3

4. HYPERBOLA (Plane shallower than cone edge)
   A = 0     B = 2     C = 1     D = -3
   A = 1     B = 2     C = 0.5   D = -2
   A = 2     B = 1     C = 0     D = -3


UNDERSTANDING THE CLASSIFICATION
--------------------------------

The conic type depends on the angle between the cutting plane and
the cone's axis compared to the cone's half-angle:

- If plane angle > 90°-tolerance: CIRCLE
- If plane angle > cone half-angle: ELLIPSE
- If plane angle ≈ cone half-angle: PARABOLA
- If plane angle < cone half-angle: HYPERBOLA

For default k=1.0, the cone half-angle is 45°.


ECCENTRICITY VALUES
-------------------
- Circle:    e = 0
- Ellipse:   0 < e < 1
- Parabola:  e = 1
- Hyperbola: e > 1


KEYBOARD SHORTCUTS
------------------
- Click on input field to edit values
- Press Enter or Tab to confirm input
- Press Escape to cancel input
