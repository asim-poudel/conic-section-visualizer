================================================================================
                           1. PROJECT OVERVIEW
================================================================================

This application provides real-time 3D visualization of conic sections formed
by the intersection of a plane with a double-napped cone. The four types of
conic sections (Circle, Ellipse, Parabola, Hyperbola) are computed analytically
using parametric equations and rendered with OpenGL.

Key Features:
- Real-time 3D rendering with OpenGL
- Parametric cone-plane intersection computation
- Automatic conic section classification
- Interactive parameter adjustment
- Camera controls (rotation, zoom)
- Anti-aliased smooth rendering

================================================================================
                        4. MATHEMATICAL ALGORITHMS
================================================================================

4.1 CONE EQUATION
-----------------
The double-napped cone is defined by:
    x² + y² = k²z²

Where:
- k = slope parameter (default: 1.0)
- For k=1, cone half-angle = 45°
- Upper nappe: z ≥ 0
- Lower nappe: z ≤ 0

4.2 PLANE EQUATION
------------------
The cutting plane is defined by:
    Ax + By + Cz + D = 0

Where (A, B, C) is the normal vector and D is the distance parameter.

4.3 PARAMETRIC INTERSECTION ALGORITHM
-------------------------------------
The intersection is computed using parametric equations:

For UPPER NAPPE (z ≥ 0):
    x(θ) = k·z(θ)·cos(θ)
    y(θ) = k·z(θ)·sin(θ)
    z(θ) = -D / (A·k·cos(θ) + B·k·sin(θ) + C)

For LOWER NAPPE (z ≤ 0):
    x(θ) = -k·z(θ)·cos(θ)
    y(θ) = -k·z(θ)·sin(θ)
    z(θ) = -D / (-A·k·cos(θ) - B·k·sin(θ) + C)

Sampling: 720 points per nappe (θ from 0 to 2π)

4.4 CONIC CLASSIFICATION ALGORITHM
----------------------------------
Classification is based on the angle between the cutting plane and cone axis:

    plane_angle = 90° - arccos(|normal · axis|)
    cone_half_angle = arctan(k)

Classification Rules:
┌────────────────────────────────────────────────────────────────┐
│ Condition                               │ Conic Type          │
├────────────────────────────────────────────────────────────────┤
│ plane_angle ≈ 90°                       │ CIRCLE              │
│ plane_angle > cone_half_angle           │ ELLIPSE             │
│ plane_angle ≈ cone_half_angle           │ PARABOLA            │
│ plane_angle < cone_half_angle           │ HYPERBOLA           │
└────────────────────────────────────────────────────────────────┘

4.5 ECCENTRICITY FORMULAS
-------------------------
Circle:     e = 0
Ellipse:    e = cos(plane_angle) / cos(cone_half_angle)    [0 < e < 1]
Parabola:   e = 1
Hyperbola:  e = cos(cone_half_angle) / cos(plane_angle)    [e > 1]

4.6 INSIDE-CONE FILTERING (For Hyperbola)
------------------------------------------
For hyperbola rendering, points where the plane exits the cone are filtered:

Algorithm:
1. For each intersection point (x, y, z)
2. Compute inner point: (xi, yi) = (0.95x, 0.95y)
3. Find zi on the plane: zi = (-A·xi - B·yi - D) / C
4. Check if inside cone: xi² + yi² < k²·|zi|²
5. If outside, skip the point

================================================================================
                          5. GRAPHICS RENDERING
================================================================================

5.1 OPENGL CONFIGURATION
------------------------
- OpenGL Mode: Fixed-function pipeline
- Shading Model: Gouraud (GL_SMOOTH)
- Depth Buffer: Enabled (GL_DEPTH_TEST)
- Blending: Alpha blending (GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA)
- Anti-aliasing: GL_MULTISAMPLE, GL_LINE_SMOOTH, GL_POLYGON_SMOOTH

5.2 LIGHTING SETUP
------------------
Two-light system:
- Light 0: Position (5, 5, 10), bright white, main illumination
- Light 1: Position (-5, -3, 5), blue-tinted fill light

Light Model:
- Two-sided lighting enabled for conic section
- Local viewer for better specular calculation

5.3 RENDERING OBJECTS
---------------------

CONE:
- Rendered using gluCylinder
- Segments: 48 (circumference), Layers: 24 (height)
- Color: White (0.95, 0.95, 0.97) with 85% opacity
- Both nappes rendered (upper and lower)

PLANE:
- Rendered as subdivided quad grid
- Divisions: 20 x 20
- Size: 10 x 10 units
- Color: Dark grey (0.25, 0.28, 0.32) with 50% opacity

CONIC SECTION:
- Rendered as 3D solid with thickness
- Thickness: 0.05 units
- Components:
  * Top surface: GL_TRIANGLE_FAN
  * Bottom surface: GL_TRIANGLE_FAN
  * Edge band: GL_QUAD_STRIP with per-vertex normals
- Color: Bright yellow (1.0, 1.0, 0.0)
- Material: Ambient (0.5, 0.5, 0), Diffuse (1, 1, 0), Specular (1, 1, 0.9)
- Shininess: 100 (high gloss)

AXES:
- X-axis: Red (1.0, 0.2, 0.2)
- Y-axis: Green (0.2, 1.0, 0.2)
- Z-axis: Blue (0.2, 0.2, 1.0)
- Length: 3 units
- Line width: 2 pixels

5.4 CAMERA SYSTEM
-----------------
- Projection: Perspective (FOV: 45°)
- Near clip: 0.1, Far clip: 100.0
- Default position: Distance -15 units
- Default rotation: X=30°, Y=45°
- Controls: Mouse drag for rotation, scroll for zoom

10.1 RUNNING THE APPLICATION
----------------------------
From source: python main.py
Executable: Double-click ConicVisualizer.exe

10.2 PLOTTING CONIC SECTIONS
-----------------------------

CIRCLE (e = 0):
    Plane perpendicular to cone axis
    Example: A=0, B=0, C=1, D=-2

ELLIPSE (0 < e < 1):
    Plane steeper than cone edge
    Example: A=0, B=1, C=2, D=-3

PARABOLA (e = 1):
    Plane parallel to cone edge
    Example: A=0, B=1, C=1, D=-2

HYPERBOLA (e > 1):
    Plane shallower than cone edge
    Example: A=0, B=2, C=1, D=-3

10.3 TIPS
---------
- Use C=1, D=-2 with A=B=0 for horizontal circle
- Increase |D| to move plane away from apex
- Adjust k to change cone steepness
- Rotate view to see both nappes for hyperbola
